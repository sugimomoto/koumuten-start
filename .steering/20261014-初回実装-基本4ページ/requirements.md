## 今回やること

サイトがまだ空（テーマもプラグインも中身なし）の状態から、**4つのページ**を作って動く形にする。
あわせて、山田工務店が自分たちで施工事例を更新できる管理画面と、何度実行しても同じ状態になる中身作成スクリプトを用意する。

| ページ | 要件書の要件 |
|---|---|
| トップページ | R-12 |
| 会社の紹介 | R-06 |
| 施工事例（一覧・詳細・種類での絞り込み・費用の概算） | R-01 / R-02 / R-03 |
| お問い合わせ（フォーム・電話） | R-09 / R-10 |

非機能要件：N-01（スマホで見やすい）／N-02（自分たちで更新できる。今回は施工事例のみ）／N-03（迷惑メール対策）

## 受け入れ条件（要件書から転記。これをそのまま E2E テストにする）

### R-12 トップページ
- [ ] 来訪者がトップページを開くと、施工事例の新着が写真つきで見える
- [ ] 来訪者がトップページを開くと、電話番号が見える
- [ ] 来訪者がトップページから、施工事例の一覧・会社の紹介・問い合わせへ移動できる

### R-06 会社の紹介
- [ ] 来訪者が会社の紹介のページを開くと、会社の紹介が読める

### R-01 施工事例
- [ ] 来訪者が施工事例の一覧を開くと、施工事例が写真つきで並んで見える
- [ ] 来訪者が施工事例を1件開くと、その事例の写真が見える
- [ ] 来訪者が施工事例を1件開くと、場所・工期・築年数が見える
- [ ] 事務担当が管理画面で施工事例を追加して公開すると、来訪者が見る一覧にその事例が出る

### R-02 施工事例の費用（概算）
- [ ] 来訪者が、費用を入力した施工事例を開くと、「約○○万円」の形で概算の費用が見える
- [ ] 来訪者が、費用が空欄の施工事例を開くと、費用はどこにも表示されない

### R-03 施工事例の種類での絞り込み
- [ ] 来訪者が施工事例の一覧で「リフォーム」を選ぶと、リフォームの事例だけが並び、ほかの種類の事例は出ない
- [ ] 来訪者が「新築」を選ぶと、新築の事例だけが並ぶ
- [ ] 来訪者が「修繕」を選ぶと、修繕の事例だけが並ぶ
- [ ] 来訪者が絞り込みを解除すると、すべての種類の事例が並ぶ

### R-09 電話での問い合わせ
- [ ] 来訪者がどのページを開いても、電話番号が目立つ位置に見える
- [ ] スマホで見ている来訪者が電話番号を押すと、電話をかける動作になる（`tel:` のリンクになっている）

### R-10 問い合わせフォーム
- [ ] 来訪者が問い合わせフォームを開くと、ご相談の種類を選ぶ欄があり、リフォーム・新築などから選べる
- [ ] 来訪者が必要な項目を入れて送信すると、受け付けたことがわかる表示が出る
- [ ] 来訪者が必要な項目を空のまま送信すると、送信されず、どこを直せばよいかがわかる表示が出る
- [ ] 問い合わせが送信されると、山田工務店にメールで知らせが届く
- [ ] 迷惑メール（スパム）対策により、自動送信とみなされる送信は受け付けられない

### N-01 スマホで見やすい
- [ ] 来訪者がスマホの幅（375px）で各ページを開くと、横にはみ出さずに読める大きさの文字で表示される
- [ ] 来訪者がスマホの幅でメニューを開くと、各ページへ移動できる

### N-02 自分たちで更新できる（今回は施工事例のみ）
- [ ] 事務担当が管理画面にログインして、施工事例を、制作者に頼まずに追加・編集・公開できる

### N-03 迷惑メール対策
- [ ] R-10 の受け入れ条件（自動送信とみなされる送信は受け付けられない）を満たす

## 制約

- ローカルは `@wordpress/env`（http://localhost:8890 ）。`npm start` で起動
- テーマ `wp-content/themes/koumuten/` は**見た目だけ**。カスタム投稿タイプ・カスタムフィールド・フォーム処理は自作プラグイン `wp-content/plugins/koumuten-core/` に置く（テーマを替えてもデータが消えないように）
- ACF・Contact Form 7 などの既製プラグインは使わず、コードで書く
- 日本語のサイト。スマホでも見やすくする
- 固定ページ・メニュー・サンプルデータは、**何度実行しても同じ状態になる** `bin/setup-content.sh`（`--remote` で本番）で作る。GitHub Actions がこの名前で呼ぶ
- 出力のエスケープ・入力のサニタイズ・nonce 検証・権限チェックを徹底する
- 本番で動かす E2E テストには `@readonly` を付ける。書き込むテストは `isLocal` でスキップする
- 本番への公開は今回の作業に含めない（ローカルで全テスト 🟢 になるところまで）

## 確認したいこと

1. **R-12 トップページは制作側で補った要件**（打ち合わせに発言がない）。入口に「施工事例の新着・電話番号・各ページへの入口」を置く形で進めてよいか
2. **費用の入れ方**：`300` のように万円の整数で入れてもらい「約300万円」と出す形で進める。「約300〜400万円」のような**幅で出したい場合は作りが変わる**ので、必要なら教えてほしい
3. **ご相談の種類の選択肢**：事業内容の3つ（リフォーム・新築・修繕）＋「その他」で進める。[03:51] は「リフォームか新築かとか」までの発言
4. **電話番号・会社の紹介の本文などの実データ**は未入手。今回はダミーを入れて作り、あとから管理画面で差し替えられる形にする
